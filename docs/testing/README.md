# Testing evidence

This directory holds verification transcripts and self-review records from
earlier hardening rounds. The transcripts are kept as they were recorded.

Some transcripts run `scripts/verify_round6_hardening.py` through
`scripts/verify_round9_hardening.py` or `scripts/verify_batch1_1373.py`. Those
one-off verifiers now live in `scripts/archive/` under the same file names
(#1986).
