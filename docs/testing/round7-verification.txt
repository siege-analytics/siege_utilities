Scope and results
1. DuckDB query materializes every returned typed relation through a shared
   positional ST_AsWKB projection, including INSERT/UPDATE/DELETE RETURNING.
   DML without RETURNING uses execute/fetchdf so Count is retained. Dispatch
   uses parsed statement metadata and DuckDB tokenization; prepared EXECUTE
   inspects the prepared definition without executing the mutation to probe it.
2. to_pandas returns query frames unchanged and materializes external typed
   relations through the same WKB boundary. index_points therefore preserves
   decodable geometry. to_geodataframe decodes the selected WKB column.
3. Query frames outlive their engine and retain the original values after a
   source-row delete. No lazy relation escapes query(). Memory use remains
   proportional to the eager result size, as requested.
4. Census dataset-path rejection checks hostname == api.census.gov. Other hosts
   accept arbitrary proxy paths. Existing slash and terminal-data normalization,
   cbp/acs rejection, and earlier proxy shapes are preserved.
